Shintsugi - changelog
=====================

Newest version first. Versions are dates (year.month.day). Players update by running the new Install.cmd; your
progress in %LOCALAPPDATA%\Shatterline is kept. "Server part" changes only matter to server hosts.


2026.11.11
----------
Skin packs
- The new skins moved out of the mod into skin packs: separate downloads on the mod page (optional files
  "Skin pack - ..."), one per set of skins, each with its own Install.cmd and Uninstall.cmd. Take only the sets you
  like. README.txt lists the packs and what is in each.
- Updating from an earlier version: the mod's new shintsugi.pak no longer has the skins. To keep wearing them,
  install their packs after the mod. Without its pack, a skin is no longer in the customization screen.
- Other players see a pack's skins on you when they have that pack too. Without it, the mod shows them a default
  look in its place: the agent's default outfit for a whole outfit, the agent's default hat, mask or hair for
  those. They can hit you as usual.
- The installers list the packs' models in the game's asset catalog (game01\assetcatalog.pak, the index the game
  finds its models in), the way the game lists its own. The game's own catalog is kept as assetcatalog.pak.orig
  and put back when the last pack with models is removed. After Steam checks the game files or updates the game,
  run Install.cmd again.
- The mod is a much smaller download now (game01\shintsugi.pak about 3 MB).
- Install.cmd leaves installed skin packs as they are; Uninstall.cmd removes the mod and every skin pack.
- Skin packs need the full mod; they don't work with Shintsugi Lite.

New skins
- Brisa: Hexagon, Pixel, Jungle, Trench, Forest and Lush Turtleneck + Leggings (pack Brisa Camo) and Celestial
  Empire Turtleneck + Leggings (pack Brisa Outfits), with the patterns of the weapon paints.

Server part
- New: InstallServer.cmd and UninstallServer.cmd. They find the server in the Steam libraries (or take the server
  folder by drag and drop) and refuse to run while a server is running.
- The skins' server files moved into the skin packs: each pack's server folder has its
  shintsugi_skins_<pack>_server.pak and the same InstallServer.cmd. Without a pack's server file, players wearing
  its skins appear in the default look in matches.
- InstallServer.cmd also lists the packs' models in the server's asset catalog: without that, the server can't
  register hits on a player wearing a pack's whole outfit. Run it again after a server update.

Shintsugi Lite
- No skin packs in Lite: they need the full version's version.dll. Lite can't show what it doesn't have: a whole
  outfit of a pack makes the wearer's body invisible in Lite, and a pack's hat, mask or hair leaves that part
  empty. Hits on them still count.


2026.11.09
----------
Progress safety
- Fixed: if your progress file could not be read (for example a typo after editing it by hand), the mod replaced it
  with default values at the next start, and your materials, perks, carried gear and badge were lost. Now the file
  is left as it is and nothing is saved until it is fixed; offline_profile.log says so.
- Fixed: if your progress file was locked for a moment at game start (antivirus scan, a sync tool), the mod treated
  you as a new player and saved the starter wallet over your progress. Now it waits briefly, and if the file still
  can't be opened it leaves it alone for that session.
- Fixed: unusual characters in a saved item or badge name could make the progress file unreadable.
- New: offline_profile.json.bak, a copy of your progress from before each game session's first save. If a session
  goes wrong, close the game and copy it over offline_profile.json.
- New: CollectLogs.cmd puts the logs a bug report needs into one zip (shintsugi_logs.zip).

Squads
- Security: data from other players in a squad is now checked before it reaches the squad screens. A player who
  joined without an invite and ignored the kick could otherwise show false squad entries or send the squad to a
  server of their choice. If the lead of your squad ever goes to such a player, you leave the squad.
- Fixed: after the leader handed the lead on, players invited by the old leader were kicked when they joined, and
  the old leader kept showing them as invited.
- Fixed: an invite sent while you were joining another squad was never delivered and showed as sent forever. Only
  the leader invites, so this now just fails (logged).
- Fixed: inviting a friend and right away accepting someone else's invite could leave you in two squads at once.
- Fixed: long Cyrillic or Japanese Steam names could be cut in the middle of a letter.

After-match screens
- Fixed: after a match whose medals screen didn't come, the next match's medals screen could show an extra copy of
  your hero.

Expeditions
- Fixed: a PvP match or a co-op mission between two expeditions cleared the gear you carried out of the last
  expedition. Carried gear now changes only after an expedition (and, as before, a failed one clears it).


2026.11.08
----------
First public release.
- Progression saved on your PC: materials, perk levels bought per agent, carried gear; starter wallet for new players.
- Classic lobby with server list; Missions screen lights co-op missions being played on listed servers.
- Armory with all 27 weapons, skins, paints, stickers, trinkets.
- After-match screens: MVP, medals, session details.
- Squads with Steam friends.
- New skins: Brisa Star Ray Outfit and Winter set, Pill Blackgold set, Malva Gilded set, Mongoose Bloodstream Cyber
  Soldier.
- Server part (optional download): new skins in matches, badges shown to other players, expedition fixes, kill cam.
